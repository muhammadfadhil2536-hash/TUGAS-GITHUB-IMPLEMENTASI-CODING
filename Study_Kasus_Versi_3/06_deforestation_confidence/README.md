# 6. Deforestation & Satellite AI — Skor Keyakinan Alert

**Masalah:** Banyak alert perubahan tutupan lahan perlu diurutkan untuk pemeriksaan lebih lanjut. Contoh ini memperlihatkan bagaimana fitur citra dan ketidakpastian dapat dicatat bersama.

**Metode:** Random Forest memprediksi kelas perubahan dari fitur sintetis, lalu menampilkan probabilitas kelas tertinggi sebagai skor keyakinan model.

**Jalankan:** `python alert_confidence.py`

Ini bukan analisis citra satelit asli. Probabilitas model bukan probabilitas kebenaran yang terkalibrasi dan tidak membuktikan penyebab deforestasi.
