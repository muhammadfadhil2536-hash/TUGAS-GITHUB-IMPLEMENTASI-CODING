# Unggah ke GitHub

1. Ekstrak ZIP ke folder.
2. Buat repository baru di GitHub.
3. Jalankan terminal di folder ini:
   ```bash
   git init
   git add .
   git commit -m "Tambah studi kasus versi 3"
   git branch -M main
   git remote add origin https://github.com/USERNAME/NAMA-REPO.git
   git push -u origin main
   ```
4. Ganti `USERNAME/NAMA-REPO` dengan repository sendiri.
