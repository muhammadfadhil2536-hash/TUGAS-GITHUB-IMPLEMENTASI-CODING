# 4. Machine Learning — Klasifikasi Pesan Layanan Kampus

**Masalah:** Pesan masuk seperti pertanyaan Wi-Fi, kartu mahasiswa, atau jadwal kelas perlu diarahkan ke unit yang tepat.

**Metode:** Pipeline TF-IDF dan Logistic Regression untuk klasifikasi teks dasar.

**Jalankan:** `python ticket_classifier.py`

Data teks kecil ini hanya contoh. Untuk penggunaan nyata dibutuhkan dataset lebih besar, pengujian bias, dan pemeriksaan manusia.
