# 2. HPC — Simulasi Monte Carlo Mengestimasi Pi

**Masalah:** Menunjukkan bagaimana komputasi dapat dibagi ke beberapa proses untuk menjalankan banyak percobaan acak.

**Metode:** Menghasilkan titik acak dalam persegi dan menghitung proporsi titik yang berada di dalam seperempat lingkaran.

**Jalankan:** `python monte_carlo_pi.py`

Estimasi berubah antar-run dan hasil waktu dipengaruhi perangkat. Ini demo pembelajaran, bukan benchmark profesional.
