# Study Kasus Versi 3 — Proyek Terapan

Paket ketiga menggunakan skenario baru yang berbeda dari dua paket sebelumnya.

## Proyek
1. Analytics & AI: deteksi transaksi tidak biasa pada kantin kampus.
2. HPC: simulasi Monte Carlo untuk memperkirakan nilai pi dengan pekerjaan yang dibagi ke beberapa proses.
3. GIS: analisis cakupan evakuasi terhadap titik kumpul bencana dengan koordinat ilustratif.
4. Machine Learning: mengelompokkan pesan layanan kampus menjadi kategori layanan.
5. HCI & Data Visualization: analisis dan visualisasi waktu respons layanan mahasiswa.
6. Deforestation & Satellite AI: alur penilaian keyakinan alert perubahan tutupan hutan menggunakan fitur citra sintetis.

## Instalasi
```bash
pip install -r requirements.txt
```
Baca README tiap folder untuk menjalankan script. Seluruh data sintetis dan digunakan untuk belajar, bukan sebagai hasil pemantauan atau keputusan resmi.
